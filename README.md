# 🏠 租房雷达

跨平台真实房源聚合 + 串串房识别 + 多维评分的本地找房工具。选城市 → 输价格区间 → 选区域，一键生成带图片、链接、价格、评分和风险提示的筛房报告。

## 为什么做它

市面上的找房工具要么只聚合不评分（HouseSearch 等），要么只做单点避坑（AI Rental Detective），没有一个开箱即用、同时覆盖「聚合 → 真假识别 → 评分排序 → 可转发报告」全链路的方案。本项目把这条链路全部本地化：

| 环节 | 能力 |
| --- | --- |
| 聚合 | 房天下（主力，匿名全功能）+ 贝壳（核验标签最全）+ 安居客 / 58同城（尽力源，反爬受限自动跳过） |
| 识别 | 串串房高危组合（新装修 + 远低于市价）、逼单话术、隔断嫌疑、公寓运营信号 |
| 评分 | 真实可信 30% + 性价比 25% + 风险安全 25% + 便利匹配 20%，🟢🟡🔴 三档灯 |
| 报告 | 单文件 HTML：图片 / 原链接 / 单价对比条 / 加减分说明 / 排序筛选 / ⭐收藏清单一键复制 |

## 快速开始

```bash
pip install -r requirements.txt

# 交互向导（推荐）
python cli.py

# 参数直通
python cli.py -c 成都 -p 800 2500 -d 高新 天府新区 -r 整租 --open
```

支持的参数：`-c 城市`（中文 / 拼音缩写 cd / 全拼 chengdu）、`-p 最低 最高`（只写一个数=上限）、`-d 区名…`、`-r 整租|合租`、`--owner-only`（仅业主直租）、`--pages N`（每区抓取页数）、`--cookie "..."`（贝壳登录 Cookie）、`--fang-cookie "..."`（房天下 Cookie，触发滑块验证后浏览器人工通过再复制）、`--proxy http://...`（IP 被平台限流时走代理，或设 `RADAR_PROXY` 环境变量）。区域筛选在房天下按区代码 URL 精筛，其余源本地过滤兜底；请求过快触发平台滑块验证时会明确提示，浏览器人工通过后把 Cookie 传给 `--fang-cookie` 即可恢复。

支持城市：北上广深、成都、杭州、重庆、武汉、西安等 48 城见 `house_radar/cities.py`。

## 评分体系（0~100，🟢≥75 放心优先看 / 🟡55~74 多留心 / 🔴<55 高风险）

- **真实可信 30%**：平台权属核验（最强背书）+25、VR/视频 +15、业主直租 +12、品牌机构 +8、维护新鲜度、信息完整度（面积/朝向/户型）
- **性价比 25%**：单价 vs 商圈（≥5 样本）→ 区域 → 全城中位数三级基准，0.8~1.05 倍为甜蜜点
- **风险安全 25%**：命中「精装/全新装修/首次出租/拎包入住」且价格 < 市价 75% → **直接判疑似串串房（🔴，总分封顶 55）**；逼单话术 -15、隔断词 -18、公寓运营 -10；核验/直租/视频加分
- **便利匹配 20%**：近地铁 +30、命中目标区域 +25、朝向楼层、整租合租匹配

## Cookie 增强（可选）

贝壳匿名只能看首页 30 条；提供登录 Cookie 可解锁区域搜索 + 翻页全量：

1. Chrome 打开 `zu.ke.com` 并登录
2. F12 → Network → 刷新 → 任一请求 → Headers → 复制 Cookie 整串
3. `python cli.py -c 成都 -p 800 2500 --cookie "整串粘贴"`

安居客 / 58同城反爬强（首次访问后有软墙），失败自动跳过不影响主流程。**闲鱼、小红书**有登录墙，HTTP 抓不了——在 ZCode 会话里让 AI 用浏览器代查即可。

## 目录

```

house_radar/
  pipeline.py         抓取→去重→评分→报告 全链路
  scoring.py          评分引擎 + 串串房信号词库
  report.py           HTML 报告生成（含收藏清单）
  cities.py           48 城映射
  scrapers/
    fang.py           房天下（主力源，价格/区域/户型/直租筛选全开）
    beike.py          贝壳（匿名首页 30 条 / Cookie 全量）
    anjuke.py         安居客（尽力源）
    wb58.py           58同城（尽力源）
reports/              生成的 HTML 报告
data/                 每次运行的房源 JSON 存档（可做价格走势对比）
```
