# 🏠 租房雷达

跨平台真实房源聚合 + 串串房识别 + 多维评分的本地找房工具。选城市 → 输价格区间 → 选区域，一键生成带图片、链接、价格、评分和风险提示的筛房报告。

> 单文件 HTML 报告，无需起服务；数据抓取 → 识别 → 评分 → 报告全链路本地完成，不上传任何数据。

## 为什么做它

市面上的找房工具要么只聚合不评分（HouseSearch 等），要么只做单点避坑（AI Rental Detective），没有一个开箱即用、同时覆盖「聚合 → 真假识别 → 评分排序 → 可转发报告」全链路的方案。本项目把这条链路全部本地化：

| 环节 | 能力 |
| --- | --- |
| 聚合 | 房天下（主力，匿名全功能）+ 贝壳（核验标签最全）+ 安居客 / 58同城（尽力源，反爬受限自动跳过） |
| 识别 | 串串房高危组合（新装修 + 远低于市价）、逼单话术、隔断嫌疑、公寓运营信号 |
| 评分 | 真实可信 30% + 性价比 25% + 风险安全 25% + 便利匹配 20%，🟢🟡🔴 三档灯 |
| 报告 | 单文件 HTML：图片 / 原链接 / 单价对比条 / 加减分说明 / 排序筛选 / ⭐收藏清单一键复制 |

## 快速开始

```bash
pip install -r requirements.txt

# 交互向导（推荐）
python cli.py

# 参数直通
python cli.py -c 成都 -p 800 2500 -d 高新 天府新区 -r 整租 --open
```

要求 Python 3.9+。核心依赖仅 `requests`；`curl_cffi`（Chrome TLS 指纹仿真，显著降低被反爬标记概率）建议安装，未装时自动回退。

## 参数说明

| 参数 | 说明 |
| --- | --- |
| `-c 城市` | 中文 / 拼音缩写（cd）/ 全拼（chengdu），48 城见 `house_radar/cities.py` |
| `-p 最低 最高` | 月租区间（元）；只写一个数 = 价格上限 |
| `-d 区名…` | 区域列表，空格分隔；房天下按区代码 URL 精筛，其余源本地过滤兜底 |
| `-r 整租\|合租` | 整租 / 合租 |
| `--owner-only` | 仅业主直租（房天下 a21 个人房源） |
| `--pages N` | 房天下每个区域抓取页数（默认 2） |
| `--cookie "..."` | 贝壳登录 Cookie，解锁区域/筛选/翻页全量 |
| `--fang-cookie "..."` | 房天下 Cookie，滑块验证后复用会话（见下） |
| `--proxy http://...` | HTTP/SOCKS5 代理，IP 被平台限流时换出口（或设 `RADAR_PROXY` 环境变量） |
| `--open` | 生成后自动用浏览器打开报告 |

## 评分体系（0~100，🟢≥75 放心优先看 / 🟡55~74 多留心 / 🔴<55 高风险）

- **真实可信 30%**：平台权属核验（最强背书）+25、VR/视频 +15、业主直租 +12、品牌机构 +8、维护新鲜度、信息完整度（面积/朝向/户型）
- **性价比 25%**：单价 vs 商圈（≥5 样本）→ 区域 → 全城中位数三级基准，0.8~1.05 倍为甜蜜点
- **风险安全 25%**：命中「精装/全新装修/首次出租/拎包入住」且价格 < 市价 75% → **直接判疑似串串房（🔴，总分封顶 55）**；逼单话术 -15、隔断词 -18、公寓运营 -10；核验/直租/视频加分
- **便利匹配 20%**：近地铁 +30、命中目标区域 +25、朝向楼层、整租合租匹配

## 反爬与 Cookie（重要）

各平台均部署 IP 信誉墙 + TLS 指纹识别。本项目的对策（实测结论）：

- **指纹仿真**：默认走 `curl_cffi` Chrome 指纹 + 会话预热 + 页面间礼貌延时，降低被标记概率；但对已标记 IP 无效
- **房天下滑块**：触发验证时 CLI 会明确提示。解法：浏览器打开 `zu.fang.com` → 人工拖过滑块 → F12 → Network → 任一请求 → 复制 Cookie → `--fang-cookie "整串粘贴"`，程序即可完全解封
- **贝壳**：匿名仅城市首页约 30 条推荐。Chrome 打开 `hz.zu.ke.com` 登录后同上复制 Cookie → `--cookie "整串粘贴"`，解锁区域 + 筛选 + 翻页全量；Cookie 失效会立即提示而非空耗
- **安居客 / 58同城**：反爬最强，被拦截时自动跳过并注明原因，不影响主流程；换 IP / 挂代理后可用
- **换出口**：手机热点、家用宽带或任意代理 `--proxy http://127.0.0.1:7890` 都能重置 IP 信誉

## 已知问题与局限

在使用/贡献前请先了解这些边界：

**数据源可用性**
- 安居客、58同城反爬最强，多数场景下会被拦截（自动跳过并在报告中注明），实际产出以房天下 + 贝壳为主
- 房天下/贝壳的匿名能力有限：房天下全功能但可能触发滑块验证（需人工过一次后复用 cookie）；贝壳匿名仅首页推荐，区域/筛选/翻页需登录 Cookie
- 闲鱼、小红书等登录墙平台未覆盖

**解析的脆弱性**
- 解析基于页面结构正则，平台改版即失效（tests/ 里用真实页面夹具锁定了当前结构，改版后需更新夹具与正则）
- 房天下部分个人房源条目的地区行缺少区名段，个别字段可能以商圈顶替（URL 级区域筛选不受影响）
- 安居客/58 的条目缺面积/户型等字段，评分中信息完整度分会偏低——这是数据源限制而非房源问题

**评分的边界**
- 性价比基准来自**当次抓取样本**的中位数：样本少（<20 条）或抓取被限流导致样本偏斜时，基准会失真
- 串串房判定是启发式信号规则（新装修词 + 低于市价 75%），只能标记"高危信号"，**不能替代线下核验**（权属证明、气味、CMA 甲醛检测）
- 平台标签（权属核验/业主直租）直接采信平台展示，无法二次验证

**合规**
- 仅供个人找房参考，请控制抓取频率（内置随机延时），勿高频请求或商用；数据版权归原平台
- 不存储、不上传任何抓取数据到第三方，报告与 JSON 存档均在本机
